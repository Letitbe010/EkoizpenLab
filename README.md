# EkoizpenLab

**EU** · Ekoizpenaren programazioko ariketak entrenatzeko aplikazioa (OPE, 1508 espezialitatea: *Fabrikazio Mekanikoaren Antolamendua eta Proiektuak*): lerroen orekatzea, CPM, PERT, Gantt eta Johnson-en araua. Zuzenketa deterministikoa da: bi ebazle independente eta Python orakulu bat.

**ES** · Aplicación para entrenar ejercicios de programación de la producción (OPE, especialidad 1508: *Organización y Proyectos de Fabricación Mecánica*): equilibrado de líneas, CPM, PERT, Gantt y regla de Johnson. La corrección es determinista: dos solucionadores independientes y un oráculo en Python.

Web: https://letitbe010.github.io/EkoizpenLab/

## Garapena / Desarrollo

```bash
npm install
npm run dev
npm test
npm run oracle:py   # Python oracle (pip install -r tools/oracle/requirements.txt)
```
